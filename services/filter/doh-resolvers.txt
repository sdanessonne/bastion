# Bastion — résolveurs DNS chiffrés publics (DoH / DoT / DoQ).
# Une entrée par ligne : adresse IPv4 ou préfixe CIDR. « # » = commentaire.
#
# POURQUOI : le filtrage de contenu repose sur notre résolveur DNS. La redirection
# du port 53 (voir netguard.sh) neutralise le contournement le plus courant — un
# poste configuré sur 8.8.8.8 atterrit chez nous sans le savoir. Mais DoH voyage
# en HTTPS sur le port 443, indiscernable d'un trafic web ordinaire : la seule
# parade réseau est de refuser les ADRESSES des résolveurs connus.
#
# CETTE LISTE EST UN FILET, PAS UNE BARRIÈRE : un résolveur DoH non listé passera.
# Le correctif de fond pour les postes du domaine est la stratégie de groupe
# « Interdire le DNS chiffré » (magasin GPO), qui désactive DoH dans le navigateur
# lui-même. Cette liste couvre les postes NON gérés (portable perso, téléphone).
#
# Ne lister que des adresses DÉDIÉES à un service de résolution : y mettre une IP
# de CDN mutualisé bloquerait des sites légitimes hébergés derrière la même adresse.
